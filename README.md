## 🙋 ¿Quién soy?

Soy **Rolando Miranda**, estudiante de **cuarto semestre de Ingeniería de Software** en la **Universidad Técnica de Ambato (FISEI)**, en Ambato, Ecuador.

Me interesa entender cómo funciona una aplicación de principio a fin: desde la pantalla que ve el usuario hasta la base de datos que guarda la información. Disfruto programar, ordenar el código y aprender herramientas que usan los equipos de desarrollo reales.
